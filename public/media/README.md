# BALLERZ — MEDIA

**מצב נוכחי: כל התמונות באתר אמיתיות ומעובדות.** מה שנשאר זה וידאו ה-Hero.

העיבוד שהוחל על כל צילום: `-colorspace Gray -sigmoidal-contrast 3.5,48%` + קרופ ליחס + איכות 82.
המקורות הגולמיים נשארו אצלך בתיקייה; הגרסאות המעובדות נמצאות גם ב-`BALLERZ-web/`.

---


כל מסגרת ריקה באתר מציגה את הבריף שלה על המסך (`IMG_XX · תיאור · יחס`).
כאן הרשימה המרוכזת. אין צורך לצלם הכל בבת אחת — כל קובץ שנכנס מחליף placeholder אחד.

## כללי סגנון

- שחור־לבן או צבע דהוי מאוד. בלי פילטרים חמים.
- גרעין, צל קשה, אור טבעי או אור אולם. לא סטודיו.
- קרופ קרוב. פרטים: ידיים, נעליים, קווי מגרש, זיעה, כדור.
- בלי חיוכים לתמונה, בלי פוזות. עבודה.
- בלי לוגואים של מותגים אחרים בפריים.
